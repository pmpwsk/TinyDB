# TinyDB
Cross-platform .NET library written in C# that allows you to persistently store objects in the simplest way possible.

Website: https://uwap.org/projects/tinydb

Changelog: https://uwap.org/changes/tinydb

Guides: https://uwap.org/guides/tinydb

## Main features
- Managing objects by their IDs
- Referencing other objects using foreign keys
- Keeping objects in memory to provide high speed and object identity

## Installation
You can get the NuGet package here: [Useful.TinyDB](https://www.nuget.org/packages/Useful.TinyDB/)

You can also download the source code from GitHub and add a reference to it from your project.
